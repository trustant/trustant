# Hand-maintained part of DEPS. deps.sh merges it with what it reads from
# go.mod, the npm lockfiles, acp/pi.version, acp/extensions/requirements.txt
# and oplugins/prereq.yml, then regenerates DEPS, LICENSE and NOTICE.
#
# One component per line, `|`-separated:
#
#   section | name | version | license (SPDX expression) | homepage | fetch
#
# version `*` means "take the version from the pinned source for that section"
# (go.mod for `go`, requirements.txt for `python`, prereq.yml for `prereq`); deps.sh fails when
# it cannot find one.
#
# fetch tells deps.sh where to read the component's own LICENSE/NOTICE files,
# from which NOTICE is built (`{v}` is replaced by the version):
#   npm:<spec>              npm pack of that spec
#   pypi:<name>==<version>  wheel/sdist from PyPI
#   path:<dir>              a directory in this repo
#   url:<url>[,<url>...]    raw files (LICENSE, NOTICE, ...)
#   -                       nothing to fetch (see the section note in DEPS)
#
# LicenseRef-* identifiers need a text in legal/licenses/<id>.txt.
